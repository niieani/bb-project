# bb

bb keeps a user's Git repositories consistent across machines and provides guided remediation when automatic convergence is unsafe.

## Application surfaces

**Status menu**:
The compact menu-bar surface for fleet health, urgent repositories, and quick actions. It provides a direct route to the App window.
_Avoid_: Menu-bar app, tray app

**App window**:
The full macOS surface for browsing, configuration, history, diagnostics, and guided remediation.
_Avoid_: Dashboard, main menu
