## What to build

Let the menubar run existing safe, deterministic, non-interactive repository fix actions using the targeted-operation seams. One eligible action renders Fix; several render Fix… selection. Risky, interactive, remote, and inapplicable actions remain unavailable.

## Acceptance criteria

- Go derives menubar fix capabilities from existing fix eligibility, specifications, and risk metadata without duplicating policy in Swift.
- One safe fix can be invoked by stable repository/action identifiers and streams attributable progress through the established event contract.
- Multiple safe actions are selectable; risky or interactive actions never receive one-click controls.
- Swift renders Fix/Fix…, shows active-row progress/failure, serializes mutations, and refreshes status after completion.
- Contract, eligibility/execution, model, presentation, and end-to-end tests pass; related docs are current.
