## What to build

Let the menubar identify a local repository that needs and can accept synchronization, run sync for only that repository, and stream structured progress into a row spinner and concise footer status. This tracer establishes the Go-owned capability/event contract, incremental macOS process client, single-operation coordination, failure attribution, and post-operation refresh.

## Acceptance criteria

- Status JSON exposes Sync only for actionable local repositories; remote or unsafe rows expose no mutation.
- An explicit targeted sync changes only the selected repository while using the existing sync engine and global lock.
- Machine-readable events arrive incrementally and identify operation, repository, phase/message, result, and failure.
- The menubar renders a compact Sync control, active-row spinner, concise progress/error line, disables competing mutations, and refreshes live state after completion.
- Shared-contract, Go end-to-end, Swift process-stream, model, and presentation tests pass; related docs are current.
