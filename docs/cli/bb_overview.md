## bb overview

Show repository state across machines.

```
bb overview [flags]
```

### Options

```
      --all                           Show repositories synced on every machine.
  -h, --help                          help for overview
      --include-catalog stringArray   Limit scope to selected catalogs (repeatable).
      --json                          Emit the stable JSON matrix contract.
```
