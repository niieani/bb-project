## bb log

Show the fleet sync journal.

```
bb log [flags]
```

### Options

```
  -h, --help             help for log
      --json             Emit JSON events.
      --limit int        Maximum events. (default 50)
      --machine string   Filter by machine ID.
      --repo string      Filter by repository key or name.
```

### Options inherited from parent commands

```

```
